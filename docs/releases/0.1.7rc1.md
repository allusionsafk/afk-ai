## What is in the candidate

`0.1.7rc1` includes:

- guided Windows bootstrap and installer
- hardware capability vetting
- hardware-aware model selection
- native Windows Ollama
- Open WebUI
- optional SearXNG web search
- local voice support
- health and diagnostics tooling
- local-first network guardrails

## What is not proven yet

The first Beta clean-machine run has **not yet completed the entire install to
chat path**.

That run reached Python setup, model selection, and Docker Desktop installation.
Docker then reported that virtualization support was unavailable.

The resulting product gap is clear: the installer currently discovers some
Windows virtualization, WSL, and Docker blockers too late.

## Current requirements

- Windows 11
- hardware virtualization enabled for the Docker path
- NVIDIA GPU for the primary accelerated target
- smaller CPU-only models as a slow fallback
- roughly 40 GB of free disk
- Docker Desktop
- Ollama for Windows
- Python 3.12+
- PowerShell 7

WSL 2 is the current preferred Beta Docker path. It is not a claim that every
healthy Docker Desktop configuration universally requires WSL.

Docker Desktop may require first-launch setup, Windows feature configuration,
terms acceptance, or a restart. AFK AI does not require Docker Hub sign-in for
the local stack.

## Known limitation: environment preflight

Current `master` has a reviewed design for the next installer preflight, but the
Beta candidate does not yet implement it.

The missing early classification includes cases such as:

- firmware virtualization disabled or unknown
- required Windows virtualization support missing
- Windows hypervisor not running
- WSL absent, unhealthy, or outdated when relevant
- Docker absent
- Docker installed but stopped or still starting
- Docker CLI targeting a remote context
- a required restart
- unsupported or otherwise unknown platform state

The reviewed implementation contract is:

[`docs/design/virtualization-docker-preflight.md`](../design/virtualization-docker-preflight.md)

The intended recovery model is: detect early, explain one actionable next step,
persist only bounded resume state, then live-revalidate after the user fixes or
restarts the machine.

## Privacy and network boundary

AFK AI is **local-first**, not permanently offline.

Local by design:

- model inference
- Open WebUI's local account and chat database
- Docker-published UI, search, voice, and dashboard endpoints on loopback

Network activity can still occur for:

- software downloads
- model downloads
- updates
- explicitly enabled web search
- optional online integrations chosen by the user

Ollama deliberately uses a Docker-reachable Windows host bind. The installer
later attempts to apply its Windows Firewall guardrail on physical network
adapters.

Do not describe AFK AI as if every listening socket is literally loopback-only,
or as if nothing can ever leave the PC.

## Windows security

This Beta is not a signed production installer, so Windows may warn about the
downloaded script.

Do not permanently disable Defender, Smart App Control, antivirus, UAC, or
other Windows protections merely to run the beta.

The source is public and the distribution path is integrity-pinned so users can
inspect what will run.
