# AFK LocalAI Friend Beta 0.2.0-rc1

`0.2.0-rc1` is a prerelease candidate for Windows 11 x64. It is not a stable
release and must not be marked latest.

## Distribution

The supported tester artifact is:

```text
AFKLocalAISetup-0.2.0-rc1-x64.exe
```

The matching GitHub prerelease must also contain the SHA-256 sidecar, payload
manifest, exact-installer lifecycle report, and upgrade lifecycle report. Do
not distribute a source-built or renamed installer as this candidate.

## What changed

- native AFK LocalAI setup and launcher shell
- per-user Inno Setup installer, Start Menu group, optional Desktop shortcut,
  Installed apps entry, and normal uninstaller
- early Windows, virtualization, WSL, Docker, and hardware preflight
- reason-coded, resumable prerequisite recovery with live revalidation
- hidden PowerShell/Python child processes during normal operation
- persistent progress, logs, diagnostics, About/version, and support surfaces
- user state outside replaceable program files
- deterministic allowlisted payload with per-file hashes and source revision
- build-once release candidate and no-rebuild publication workflows

Models are selected and downloaded during provisioning. Large model weights are
not embedded in the EXE.

## Qualification policy

The exact installer bytes offered to testers must pass the full clean install,
launch/self-test, upgrade/state-preservation, and uninstall lifecycle. The
publication workflow verifies the candidate SHA-256 and both certified
lifecycle reports before creating a GitHub prerelease.

This source revision includes local lifecycle evidence, but a GitHub prerelease
should be created only from a successful manual release-candidate workflow on
the repository default branch. Stable publication remains blocked until an
explicit later stable version is configured and its exact bytes pass the same
gate.

## Supported path and remaining qualification

The primary path is Windows 11 x64, Docker Desktop using a healthy local Linux
container engine, WSL 2 where required, Ollama for Windows, and an NVIDIA GPU.
A smaller CPU-only configuration is supported but slow.

Before broadening beyond Friend Beta, run the published EXE on at least one
additional clean Windows 11 machine with disposable state and complete the
real prerequisite downloads, any required reboot/resume, model provisioning,
Open WebUI first launch, local inference, upgrade, and uninstall. Code signing
is also still required to remove unsigned-publisher friction.
